# Security policy

OmarchySync is a private prototype and is not an official Omarchy component.
Please do not rely on it for production security decisions.

If you believe you have found a security issue, do not publish exploit details
in a public issue. Contact the project owner privately first and include only
the minimum information needed to reproduce the issue. For issues involving
Omarchy itself, use Omarchy’s private security process at
`security@omarchy.org`.

Do not include passwords, private keys, certificates, personal data, or live
machine identifiers in reports. Sensitive implementation details should be
shared only with the people responsible for reviewing them.
